# PlumeSQL extensions

The extensions the PlumeSQL Extensions side tab installs from: saved
queries, saved commands and grid modules, one directory each under
`extensions/`, reviewed before they are merged and published from here
as the marketplace catalog. PlumeSQL itself is at
[plume.hercstack.com](https://plume.hercstack.com).

To use them, open the Extensions tab in the app: the catalog is this
repository. To write one, or to propose a change, start with
[extensions/README.md](extensions/README.md), which describes the three
kinds, the manifest, the review and the tools that check a directory
before it is sent in.
